**آخر تحديث:** 30 أكتوبر 2026. اكتملت المراحل **01–09 و11 و12** وظيفياً واختُبرت آلياً: **322/322** فحص API وصفحات و**70/70** اختبار `.NET`، مع مزامنة ناجحة (`Success`) على مصادر الجامعة الحقيقية. رابط التشغيل المحلي المعتمد الآن `https://localhost:7275` (وHTTP على `5275`)؛ يختلف المضيف عن `127.0.0.1` المستخدم للمشروع الآخر حتى لا تتشارك كوكيز الدخول بين المنفذين. تبقى بوابة PostgreSQL 17 على GitHub Actions معلّقة، والقالب الحقيقي للشهادة، واختبار SMTP فعلي.

**فحص عطل الأزرار (30 أكتوبر):** تبيّن أن نسخة خادم محلية انتهت بينما بقيت صفحة الأدمن مفتوحة؛ فتح رابط جديد أعاد `ERR_CONNECTION_REFUSED`. بعد تشغيل Release كعملية مستقلة، نجح فحص `/health` وإعادة تحميل صفحة الحسابات مع بقاء جلسة الأدمن. من الواجهة فُتحت نوافذ الحساب المحلي والأدوار والصلاحيات وعرض الكلمات (الأخيرة تطلب إعادة تحقق)، وحُفظ استثناء منع مؤقت لصلاحية حساب اختبار ثم أُعيد إلى الوراثة بنجاح. أُعيد تشغيل حزمة HTTP على المنفذ 7275: **322/322**، وتشمل إنشاء حساب محلي وتعديل الصلاحية وإعادة التحقق وكشف الكلمات. أُضيف `tools/api-tests/start-local.ps1` لتشغيل نسخة Release مستقلة، والتحقق من ملكية المنفذ وصحة التطبيق، وانتظار اكتمال الإقلاع.

**عزل جلسات المشروعين:** اختلاف المنفذ وحده لا يعزل كوكيز المتصفح على المضيف نفسه؛ الأسماء `zu_at` و`zu_rt` و`zu_ctx` ثابتة في الحزمة 03. ثُبّت `localhost:7275` لهذا المشروع في إعدادات التشغيل وأدوات الاختبار، مع إبقاء `127.0.0.1:7165` للمشروع الآخر. نجح دخول الأدمن في المتصفح عبر `localhost` بعد إعادة تشغيل نسخة Release، ونجح فتح صفحة الحسابات وحوار الإنشاء. أُعيد فحص HTTP على `https://localhost:7275`: **322/322**. يجب استخدام رابط `localhost` في المتصفح لهذا المشروع.

**إصلاح تفاعلات الواجهة:** في فحص زر تعطيل الحساب ظهر الخطأ `prompt() is not supported` من المتصفح المضمّن؛ فحوص HTTP السابقة لم تكشفه. أُضيف حوار داخل الصفحة في `site.js` مع دعم نص السبب والتأكيد والإلغاء وEscape، واستُبدلت جميع استدعاءات `window.prompt/confirm` الـ32 في 15 ملف JavaScript. استُبدل أيضاً `alert()` في زر «قبل/بعد» بسجل التدقيق بحوار قراءة داخل الصفحة. نجح `node --check` لـ53 ملفاً، وبناء Release بلا تحذيرات، وفحص HTTP **322/322**. تحقّق المتصفح من حوار سبب تعطيل الحساب وحوار تأكيد أرشفة الدورة وحوار تفاصيل التدقيق، وأُلغي فحصا التعطيل والأرشفة دون تغيير البيانات. **بقية التدفقات التفاعلية تحتاج UAT؛ لا تكفي نتيجة HTTP وحدها للحكم على عمل كل زر.**
