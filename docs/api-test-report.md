## 5. فحوصات الأمان والسلوك المختبرة

- CSRF إلزامي على جميع عمليات `POST/PUT/PATCH/DELETE` ويُرفض بـ`400 CSRF_INVALID` (مصادقة، إعدادات، تلميحات، ملفات، مزامنة، شهادات).
- الجلسات: كوكيز `HttpOnly/Secure/SameSite=Strict`، رفض الوصول بلا جلسة (`401`)، ورفض الدور غير المخوّل (`403 FORBIDDEN`).
- تجاوز الصلاحيات: منع العميد من صفحات وأوامر الأدمن/الجودة، ومنع الجودة من سجل التدقيق، ومنع إسناد أدوار الموظفين لحسابات `Local`.
- فحص التزامن المتفائل (`xmin`) يرفض النسخ القديمة بـ`409 CONFLICT`.
- غلاف الاستجابات `{ok,data}` / `{ok:false,code,message,fieldErrors}` مطبّق على كل مسارات `/api/*`، والملفات الثنائية تُمرَّر بلا تغليف.
- التحقق العام للشهادة لا يتطلب مصادقة ولا يكشف بيانات إضافية عند مرجع غير معروف.

## 6. الفجوات المتبقية وحكم الجاهزية

### 6.1 ما هو مُنجز ومُختبر
المراحل **01–09، 11، 12** مكتملة وظيفياً ومُختبرة آلياً (322 فحصاً + 70 اختبار .NET): البنية والمجال، المخطط والبذرة، الهوية والصلاحيات والاعتمادات، المزامنة الجامعية على مصدر حقيقي، الدورات والمقترحات والاعتماد والتسجيل والإلغاء، المحاضرات والحضور والامتحانات والأهلية، الشهادات وقالبها وPDF والتحقق العام، التقييم والأثر والاحتياجات، الشهادات المهنية، الإشعارات وسجل التدقيق والبث الحي والمستودع، والصفحات وملفات النشر.

### 6.2 ما يمنع إعلان الجاهزية للإنتاج
1. **القالب الحقيقي وإحداثياته لم يصلَا:** قالب الشهادة النظيف ونسخة المواضع الدالة مطلوبان وفق `06 §6.5` و`QUESTIONS.md`؛ الإحداثيات الحالية تجريبية (تُختبر آلياً بقالب مُولّد). لا تُعتمد شهادة إنتاجية قبل وصولهما.
2. **بوابة Testcontainers PostgreSQL 17 لم تُشغّل:** لا يوجد Docker محلي ولا remote للمستودع؛ استُعيض عنها بـPostgreSQL 18 حقيقي (`ZU_TEST_PG`). تبقى شرط إغلاق على GitHub Actions.
3. **SMTP حقيقي غير مُختبر:** إعدادات البريد غير متاحة؛ طابور `email_outbox` يعمل ويُختبر منطقياً فقط.
4. **تحذيرات EF Core `EventId 10622`:** مرشّحات الاستعلام العامة على `User/Course/Lecture` مع علاقات مطلوبة — تحذيرات غير مانعة تُنصح بمعالجتها.
5. **`/admin/users`** ما زالت مخصّصة لطلبات المحاضرين الخارجيين، وإدارة الحسابات والأدوار عبر `/admin/credentials` (قرار تصميمي موثّق).
6. **المرحلة 10** (اختبارات القبول النهائية كمخرَج مستقل) لم تُغلَق رسمياً لعدم توفر بوابة الحاوية، رغم نجاح كل الفحوصات المتاحة محلياً.
7. **اختبار التفاعل في المتصفح:** بعد إصلاح الحوارات غير المدعومة، اختُبرت أمثلة إدارية ودورات محددة؛ بقية أزرار الصفحات تحتاج جولة UAT تفاعلية، لأن فحوص HTTP لا تشغّل JavaScript المستخدم.

### 6.3 الحكم
> المنصة **جاهزة للتجربة الداخلية (UAT)** على قاعدة `zu_lms` مع بيانات الجامعة الحقيقية. نجحت جميع فحوص HTTP الآلية (322/322)، لكن هذا لا يغطي كل تفاعلات JavaScript. يعتمد قرار النشر الإنتاجي على إتمام UAT التفاعلي، والقالب الحقيقي للشهادة، ونجاح بوابة PostgreSQL 17 على CI، واختبار SMTP فعلي.
