### تم اختباره وسليم (أدمن + عضو)
- 44 صفحة للأدمن ترجع 200 بدون أخطاء JS (أخطاء BrowserLink من Visual Studio فقط).
- رسالة كلمة المرور الخاطئة واضحة؛ الخروج يلغي الجلسة (401 بعده).
- POST بدون CSRF → 400؛ العضو ما قدر يرفع صلاحياته (403).
- لا IDOR للعضو (ملفات 1–40، الشهادات، الشهادات المهنية، الاحتياجات، المقترحات).
- XSS محجوب بالملف الشخصي؛ لا Swagger مفتوح؛ `pageSize` محدود بـ 20 والصفحة السالبة ترجع للأولى.
- الموبايل والـ RTL سليمين بدون scroll أفقي.

### ما لم يُفحص بعد
- `dotnet list package --vulnerable` (الـ shell ما خلّص تحميل، والوصول لـ NuGet/GitHub Advisories مسكّر).
