# متابعة QA والواجهة — 2026-11-05

## ما نُفذ

- رابط غير موجود و`/not-found` يعيدان HTTP 404 مع صفحة الخطأ نفسها. تحقق HTTP على نسخة Release في المنفذ 5276: 404/404، و`/login` يعيد 200.
- صفحة العضو أو الجودة المفتوحة بحساب لا يحمل الدور المناسب تعرض «لا تملك صلاحية لهذه الصفحة» دون تحميل محتواها أو تشغيل spinner الخاص بها. أخفيت روابط الجودة من قائمة الحساب الذي لا يحمل دور الجودة، ومرشحات دليل الدورات توقف حالة التحميل عند 403.
- حالة الاحتياج في `/admin/needs` تمر عبر `ZuLmsI18n`.
- المزامنة تعرض سبب المراجعة والتحذير `SKIPPED_INVALID_ROWS` بالعربية، وموجز إحصاءات واضحاً، وتفاصيل JSON قابلة للطي. صف المراجعة ذو ثلاثة إجراءات يستخدم قائمة منسدلة.
- سجل التدقيق يعرض خريطة عربية لأسباب الفشل المعروفة، ومنها `AUTH_INVALID`، مع رسالة عامة للرمز غير المعروف.
- أُضيف CI للبناء والاختبارات وفحص تنسيق `Program.cs`. النشر أصبح `workflow_dispatch` فقط، فلا يحدث تلقائياً عند أول push.
- أزيلت كلمات المرور ومفاتيح التطوير الثابتة من أدوات API، وصارت تُطلب من متغيرات البيئة. أُنشئ مستودع Git محلي داخل نسخة المشروع، بلا remote أو commit أو push.
- تصحيح لاحق: حارس عرض صفحات `/quality` يستثني صفحة الشهادات لمن يملك `certificates.issue_pending` ومسار إنشاء الدورة التاريخية لمن يملك `course.create_historical`؛ هذان المساران مقصودان للأدمن، وروابطهما تظهر له في القائمة.

## مشاكل قائمة حسب الخطورة

1. **عالية — محتوى ملفات مفقود:** 83 من 107 سجلات ملفات نشطة بلا محتوى في التخزين. راجع [الجرد الكامل](data-inventory-2026-11-05.md). أربعة لها نسخ مطابقة في التخزين الحالي. لم تُستعد أو تُحذف ملفات.
2. **متوسطة — اختبار الأدوار غير مكتمل:** تعذّر الوصول الآمن إلى نافذة المتصفح عبر أداة التحكم، لذا لم تُنفذ جولة المتصفح بكل حساب ودور، ولم تُنشأ fixture جديدة. حسابات العميد والعضو والجودة التجريبية موجودة مسبقاً، ولا يوجد حساب محاضر تجريبي واضح في الجرد. يلزم استخدام seed في قاعدة معزولة لجولة القبول.
3. **متوسطة — واجهة الموبايل غير مؤكدة:** لم يمكن قياس 28px scroll أو فحص الصفحات بصرياً على الموبايل. منتقي التاريخ وجدول الدورات وصفحات الإعدادات والأدوار ولوحة العضو موجودة في المصدر، لكن هذا لا يثبت قبولها بصرياً.
4. **منخفضة — بوابة التنسيق محدودة:** فحص `dotnet format` الشامل يفشل بسبب مخالفات تنسيق قديمة كثيرة في المشروع. CI يفحص الملف C# المعدل فقط حتى لا تتحول هذه الجولة إلى إعادة تنسيق شاملة.

## التحقق

- `dotnet test ZuLms.sln -c Release`: فشل اختبار PostgreSQL المعتمد على Testcontainers لأن Docker Engine غير متاح محلياً؛ الاختبارات الأخرى نجحت.
- `dotnet test ZuLms.sln -c Release --filter 'FullyQualifiedName!~PostgresSeedTests'`: 133 ناجحاً، واختبار واحد متجاوز أصلاً.
- `node --check` لملفات JavaScript المعدلة: نجح.
- `dotnet format whitespace ZuLms.sln --verify-no-changes --no-restore --include src/ZuLms.Web/Program.cs`: نجح.
- ملفات GitHub Actions صالحة نحوياً. لم يُنفّذ push أو نشر.
