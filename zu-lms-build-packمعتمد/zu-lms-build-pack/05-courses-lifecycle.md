# 05 — الدورة التدريبية: الحالات والانتقالات ومن يفعل ماذا

## 1. المبدأ
الدورة كيان مستقل (ملفاتها، محاضراتها، حضورها، إحصاءاتها). **حالة الدورة** (`courses.status`) موثّقة في `course_status_history` عند كل تغيير، وتظهر بشارة ملونة في كل قائمة وصفحة. التعطيل (`is_active`) والأرشفة (`is_archived`) **حقلان مستقلان** عن الحالة.

## 2. الحالات (النص العربي حرفي)
| `status` | الشارة | اللون | المعنى |
|---|---|---|---|
| `Proposed` | «مقترحة — بانتظار الجودة» | أصفر | العميد أرسل المقترح |
| `Returned` | «معادة للتعديل» | أحمر | الجودة أعادته بملاحظات |
| `Rejected` | «مرفوضة» | رمادي غامق | رفضته الجودة |
| `Approved` | «معتمدة» + شارة فرعية مشتقة | أخضر | الدورة قائمة |
| `Finished` | «منتهية» | أزرق | المحاضر أنهاها |
| `Cancelled` | «ملغية بعد الاعتماد» | أسود | أُلغيت بموافقة الجودة |

**الشارة الفرعية المشتقة (للـ `Approved` فقط، لا تُخزَّن):** «لم تبدأ» إن لم توجد محاضرة فعّالة بدأت (`starts_at <= الآن`)، وإلا «جارية».
**مجموعات العرض:** «الدورات الملغية» = `Cancelled`؛ «الأرشيف» = `is_archived`؛ «المعطّلة» = `is_active=false` (للأدمن).

## 3. جدول الانتقالات (`CourseStateMachine`) — لا انتقال غير مذكور
| من | إلى | من يفعل | الشروط | الآثار |
|---|---|---|---|---|
| — | `Proposed` | عميد | `course.propose`، نطاق كليته | إنشاء الدورة + `course_proposal_revisions(1)` + إشعار الجودة |
| `Proposed` | `Approved` | جودة/أدمن | `proposal.decide` + بيانات الاعتماد §5 | اعتماد + إشعار العميد والمحاضر |
| `Proposed` | `Returned` | جودة/أدمن | ملاحظات إلزامية | `last_return_notes` + إشعار العميد |
| `Proposed` | `Rejected` | جودة/أدمن | سبب إلزامي | أرشيف المرفوضات + إشعار |
| `Returned` | `Proposed` | عميد (صاحب المقترح) | تعديل ثم «إعادة الإرسال» | `current_revision_no++` + لقطة جديدة + إشعار |
| — | `Approved` | جودة/أدمن | إنشاء مباشر (§6) | |
| `Approved` | `Finished` | محاضر (أو الجودة للمُدارة) | `course.finish`، محاضرة واحدة فعّالة على الأقل (`attendance.min_lectures_to_finish`) | تثبيت `final_lectures_count`، `finished_at`، إعادة تقييم كل المشاركين (`06`)، إشعارات |
| `Approved` | `Cancelled` | جودة (بطلب عميد أو مباشرة) | §9 | إلغاء الشهادات، إشعارات |
| `Finished` | `Approved` | أدمن فقط (`course.reopen`) | تأكيد صريح | [م13]: تُلغى الشهادات الصادرة (`CourseReopened`) و`final_lectures_count=NULL` |
| أي | أي | أدمن (`course.force_status`) | سبب إلزامي + تحذير، **ضمن الانتقالات المعرّفة أعلاه فقط** عدا استثناء الأدمن لإصلاح الأخطاء: أي حالة → أي حالة | يُسجَّل بالتفصيل |

## 4. نموذج «اقتراح دورة وتكليف» (العميد فقط) — `/dean/propose`
**حقول (كلها تلميح `zu-hint`، العربية إلزامية والإنجليزية اختيارية):**
| الحقل | النوع | قيد |
|---|---|---|
| `title_ar`/`title_en` | نص | عربي إلزامي ≤300 |
| `track_id` | قائمة منسدلة قصيرة (محاور فعّالة) | إلزامي |
| `delivery_mode` | قائمة (وجاهي/أونلاين/مدمج) | إلزامي |
| `objectives_ar/en` | نص طويل | عربي إلزامي |
| `target_audience_ar/en` | نص طويل | عربي إلزامي |
| `total_hours` | رقم | >0، حتى خانتين عشريتين |
| `planned_start_date`/`planned_end_date` | منتقي تاريخ | النهاية ≥ البداية |
| `audience_type` | «تسجيل ذاتي لأعضاء كليتي» (`Faculty`) أو «مشاركون محددون تضيفهم الجودة» (`Named`) | إلزامي. **ممنوع** حقل قائمة أسماء |
| `registration_deadline` | منتقي تاريخ ووقت | اختياري، يظهر عند `Faculty` |
| `max_participants` | رقم | اختياري >0 |
| `has_exam` | نعم/لا | إلزامي |
| المحاضر | اختيار نوع (راديو): «من أعضاء كليتي» / «خبير من خارج الجامعة» | إلزامي |
| ↳ داخلي | منسدلة **قابلة للبحث** (`/lookups/members?centerId={كليته}`) | أعضاء كليته فقط (يُتحقق في الخادم) |
| ↳ خارجي | `name_ar` (+`en`)، `org_ar` (+`en`)، `email` (إلزامي)، **كتاب مجلس الكلية** (PDF)، **السيرة الذاتية** (PDF/DOCX) | الأسماء/الجهة/الكتاب/السيرة إلزامية (`courses.external_requires_letter_and_cv`) |
| ملاحظة | «لطلب محاضر من كلية أخرى استخدم «رفع احتياج تدريبي»» (نص إرشادي ثابت بجانب القائمة) | لا خيار لكلية أخرى |
**محاضر واحد فقط.** عند الحفظ: ينشأ `courses` بـ `origin=DeanProposal`, `proposing_center_id=كلية العميد`, `target_center_id=كليته` (إن `Faculty`)، `status=Proposed`, `course_no` من التسلسل، `instructor_kind=Internal|ExternalAccount?` — **للخارجي** يُحفظ مؤقتاً `ExternalNameOnly` ولا يُنشأ حساب (القرار عند الجودة §5). وتُحفظ المرفقات (`course_files`, `purpose=ProposalCouncilLetter|InstructorCv`) وتُسجَّل في المستودع (`09`).
**العميد يرى** في «دورات الكلية» كل مقترحاته وحالتها؛ المعاد بملاحظات الجودة **بالأحمر** في أعلى الصفحة؛ يعدّل **المطلوب فقط** (كل الحقول قابلة للتعديل مع إبقاء القيم السابقة معبّأة) ثم «إعادة الإرسال». النسخ السابقة تبقى في `course_proposal_revisions` ويستطيع العميد والجودة عرضها (للقراءة).

## 5. قرار الجودة على المقترح — `/quality/proposals`
قائمة المقترحات بحالة `Proposed` (كلية، عميد، عنوان، تاريخ الإرسال، رقم النسخة). عند الفتح: كل البيانات والمرفقات (تنزيل) والنسخ السابقة، ثلاثة أزرار:
1. **اعتماد:** نافذة بالحقول:
   - `evaluation_end_date` (إلزامي، منتهى ≥ اليوم؛ المقترح الافتراضي = `planned_end_date + evaluation.default_period_days`).
   - `audience_type` (يُسبق بقيمة العميد، يمكن تغييرها)، `target_center_id` إن `Faculty` (كلية العميد افتراضياً)، `registration_deadline`, `max_participants`, `has_exam` (يمكن تغييرها).
   - **إن كان المحاضر خارجياً:** اختيار إلزامي من ثلاثة: (أ) «مدرب خارجي مسجّل مسبقاً» → منسدلة بحث في حسابات `ExternalInstructor` (→ `ExternalAccount` بلا الرجوع للأدمن)، (ب) «إنشاء حساب لمدرب جديد» → يُنشأ `external_instructor_account_requests` ويُحال للأدمن (§7) **والاعتماد يتم فوراً** ويُكمل الأدمن الحساب لاحقاً، (ج) «إدارة الدورة القصيرة من الجودة» → `managed_by_quality=true`, `ExternalNameOnly` (§8).
   - يُنفّذ: `status=Approved`, `approved_by/at`, سجل الحالة، إشعار العميد ومحاضر الدورة الداخلي، **ظهور الدورة** للأعضاء المؤهلين وللمحاضر في «دوراتي كمحاضر».
2. **إعادة للتعديل:** ملاحظات إلزامية → `Returned`, `last_return_notes`، لقطة القرار.
3. **رفض:** سبب رسمي إلزامي → `Rejected`.
**الأدمن** يملك الإجراءات نفسها (`proposal.decide`).

## 6. الإنشاء المباشر (الجودة والأدمن) — `/quality/courses/new`, `/admin/courses/new`
نموذج المقترح نفسه مع فروق: لا «العميد/الكلية المقترحة» (اختيار اختياري «الكلية المعنية»)، `audience_type` ثلاثي (`General`/`Faculty`/`Named`) وعند `Faculty` يُختار أي مركز `is_faculty` (`target_center_id`)، المحاضر: (داخلي من **أي** كلية بالبحث) أو (خارجي مسجّل) أو (خارجي بحساب جديد → طلب للأدمن) أو (اسم فقط/دورة قصيرة مُدارة من الجودة)، `evaluation_end_date` إلزامي. عند الحفظ: `status=Approved` فوراً، `origin=QualityCreated|AdminCreated`.
**الدورات التاريخية** (`course.create_historical`): الخيار «دورة سابقة قبل إطلاق النظام» (`is_historical=true`) يسمح بتواريخ ماضية ويطلب من الجودة أو الأدمن تحديد الأعضاء وقرار نهائي لكل عضو: «ناجح/مستحق» أو «غير ناجح/غير مستحق». لا يُسأل عن وجود امتحان، ولا تُنشأ محاضرات أو حضور أو امتحان للدورة السابقة؛ قرار النجاح يعني ضمنياً استيفاء الحضور والامتحان. يحدد المُدخل فقط هل تقييم الدورة مطلوب قبل الشهادة: إن لم يكن مطلوباً تصدر شهادة الناجح مباشرة، وإن كان مطلوباً يكون التقييم الشرط الوحيد المتبقي وتصدر الشهادة فور إرساله. قياس الأثر اختياري ولا يدخل في القرار أو الشهادة. الدورة التاريخية سجل للقراءة ولا يستطيع المحاضر إنشاء أو تعديل محاضرات أو امتحانات لها.

## 7. حلقة المدرب الخارجي (الجودة ↔ الأدمن)
1. الجودة تُنشئ الطلب (§5-1-ب): الاسم، الجهة، البريد، ربط بالدورة.
2. الطلب يظهر للأدمن (`/admin/users` تبويب «طلبات المدربين الخارجيين») بحالة `PendingAdmin`.
3. الأدمن يضغط «إنشاء الحساب»: **رقم الدخول** (4 أرقام من النطاق، فريد، زر «اقترح رقماً»)، **كلمة المرور** (يُدخلها أو يولّدها، تجتاز السياسة)، يؤكد → ينشأ `users(ExternalInstructor)` + `external_instructor_profiles` + دور `ExternalInstructor`، `must_change_password=false`, `first_login_completed_at=الآن`، وتُربط الدورة (`instructor_user_id`, `instructor_kind=ExternalAccount`). الطلب `Completed` وإشعار للجودة.
4. **عند اعتماد الدورة/اكتمال الحساب** يُنشأ صف `email_outbox` (`ExternalInstructorAccount`) إلى بريد الطلب فيه رقم الدخول وكلمة المرور (فك التشفير). إن كان الحساب قد اكتمل **قبل** الاعتماد يُرسل عند الاعتماد، وإن اكتمل بعده يُرسل عند الاكتمال.
5. لا يغيّر المدرب كلمته؛ **الأدمن وحده**. لا «نسيت كلمة المرور» له.

## 8. الدورة القصيرة المُدارة من الجودة (`managed_by_quality`)
تقررها الجودة (عند الاعتماد أو الإنشاء). لا حساب للمحاضر الفعلي. تُنفّذ الجودة أعمال المحاضر بحسابها (محاضرات، حضور، امتحان، أثر، إنهاء). **اسم المحاضر الفعلي** (`instructor_name_ar/en`) يظهر في نموذج التقييم وعلى الشهادة، لا «الجودة». تظهر الدورة في مساحة المحاضر للجودة (`/instructor/courses?managed=1`) ولا تظهر لأحد غيرها. صلاحيات المحاضر لمستخدم Quality **تمر فقط** على هذه الدورات (`InstructedCourse`).

## 9. الإلغاء
- **طلب العميد (`cancellation.request`):** لدورة كليته بحالة `Approved`. زر «طلب إلغاء دورة معتمدة» ← نافذة: السبب (إلزامي) + **رفع كتاب رسمي موقّع** (إلزامي عند `courses.cancel_requires_letter`). ينشأ `course_cancellation_requests(Pending)` (واحد معلّق فقط) وتبقى الدورة تعمل حتى القرار.
- **قرار الجودة (`cancellation.decide`)** في `/quality/cancellations`: **موافقة** → `Cancelled`, `cancelled_at/by/reason`, **كل الشهادات `Issued` للدورة تصير `Revoked` بسبب `CourseCancelled`** وتظهر «ملغاة» عند التحقق، `is_archived=true` تلقائياً، سجلات الدورة وملفاتها وكتاب الإلغاء تبقى. **رفض** → الطلب `Rejected` بملاحظات.
- **إلغاء مباشر من الجودة (`course.cancel_direct`)** [م12]: السبب + كتاب رسمي إلزاميان، النتيجة نفسها.
- «الدورات الملغية» تظل ظاهرة في إحصاءات العميد والجودة والأدمن ببند مستقل مع تفاصيلها ومرفقاتها وكتاب الإلغاء.

## 10. التسجيل والمشاركون
**قاعدة الظهور للتسجيل الذاتي:** الدورة `Approved` فعّالة غير مؤرشفة، و:
- `General`: تظهر لكل مستخدم `Employee` فعّال.
- `Faculty`: تظهر لمن مركز موظفه (`employees.center_id`) = `target_center_id`.
- `Named`: **لا تظهر** للتسجيل الذاتي؛ المشاركون تضيفهم الجودة/الأدمن فقط.
**شروط الضغط على «سجّلني» (تُتحقق في الخادم بالترتيب):** `participants.self_register`؛ ليس هو محاضر الدورة [م6]؛ لم يتجاوز `registration_deadline`؛ لم يبلغ `max_participants` (يُحتسب المشاركون الفعّالون)؛ ليس مشاركاً فعّالاً أصلاً. الأخطاء: `REG_CLOSED`, `REG_FULL`, `REG_NOT_ELIGIBLE`, `REG_ALREADY`, `REG_IS_INSTRUCTOR`. النتيجة: `course_participants(SelfRegistered)`.
**إضافة (`participants.add`) وإخراج (`participants.remove`)** للجودة والأدمن، بمنتقي أعضاء قابل للبحث (يقبل أي موظف فعّال) أو عدة أعضاء دفعة. الإضافة اليدوية متاحة للدورات العادية قبل `Finished`. أما أعضاء الدورة التاريخية ونتائجهم فيُدخلون مع إنشاء السجل التاريخي نفسه، ولا تسمح شاشة الإضافة العامة بإضافة عضو بلا قرار نجاح نهائي. الإخراج يتطلب سبباً ويُعطّل الصف (`is_active=false`) **دون حذف الحضور**؛ إن كانت له شهادة سارية: تحذير ثم تُلغى بسبب `ParticipantRemoved`. تجاوز السعة من الجودة/الأدمن مسموح بتأكيد صريح. الإشعار للمشارك عند الإضافة/الإخراج.
**العميد لا يضيف مشاركين** ولا يرسل قائمة أسماء؛ يتواصل خارج المنصة.

## 11. صلاحيات الأدمن على الدورة (كل شيء قابل للتعديل)
- **تعديل أي حقل** في أي حالة (`course.edit` + `course.force_status`) مع تسجيل قبل/بعد. الجودة تعدّل (`course.edit`) الحقول التالية فقط: العناوين، الأهداف، الفئة، الساعات، التواريخ، `audience_type`/`target_center_id`/`registration_deadline`/`max_participants`، `evaluation_end_date`، `has_exam` (بقاعدة الامتحان `06 §6`)، نسبة الحضور الخاصة (`attendance_threshold_percent_override`)، المحاضر قبل `Finished`.
- **تعطيل (`course.deactivate`)** في أي مرحلة بلا موافقة الجودة: نافذة تحذير + سبب. **إن كانت للدورة شهادات `Issued`** تسأل النافذة حرفياً: «هذه الدورة لها N شهادة. ماذا تريد؟ ○ إبقاء الشهادات لدى أصحابها ○ تعطيل الشهادات أيضاً (تُخفى من بوابة التحقق ولا تظهر تفاصيلها)». الاختيار → `deactivation_certificates_action`. «تعطيل الشهادات» يضبط `certificates.is_active=false` و`hidden_by_course_disable=true` (الصفوف تبقى). الاختيار لا يُعمَّم على دورات أخرى.
- **استعادة (`course.restore`):** `is_active=true`. إن كان الاختيار السابق «تعطيل الشهادات»: لكل شهادة `hidden_by_course_disable` أعد تقييم صاحبها (`06 §5`): مستحق → `is_active=true` وتزول العلامة؛ غير مستحق → تُلغى `Revoked` بسبب `CourseDisabledRestoreIneligible` **ولا تعود**.
- **أرشفة/إلغاء أرشفة** (`course.archive`/`unarchive`) مستقلة.
- **فتح من جديد** (`course.reopen`) [م13] + **تغيير الحالة** (`course.force_status`).
- **إضافة/إخراج مشاركين**، **تعديل الحضور والامتحان والأثر والتقييم** كأي محاضر (صلاحيات `C` بتجاوز النطاق).
- كل تعطيل/أرشفة/استعادة يُسجَّل ويُرسل إشعاراً للمحاضر والجودة.

## 12. من يرى ماذا في قوائم الدورات
| الدور | القائمة |
|---|---|
| أدمن/جودة | كل الدورات (بحث + فلاتر: الحالة، الكلية، المحور، النمط، التاريخ، معطّلة، مؤرشفة) |
| عميد | دورات كليته (`proposing_center_id` أو `target_center_id` = كليته) |
| محاضر | الدورات التي هو محاضرها (`Approved`/`Finished`) |
| عضو | المتاحة للتسجيل + المسجّلة |
قائمة بحث من الخادم (`course_no`، العنوان، المحاضر) بترقيم صفحات.

## 13. إشعارات الدورة (داخل المنصة)
مقترح جديد → الجودة؛ قرار الجودة → العميد؛ اعتماد → المحاضر + (للتسجيل الذاتي) لا إشعار جماعي؛ إضافة مشارك/إخراج → المشارك؛ محاضرة جديدة → كل المشاركين الفعّالين؛ كود الحضور مفعّل → لا إشعار؛ إنهاء الدورة → المشاركون؛ طلب إلغاء/قرار → المعنيون؛ إلغاء/تعطيل/استعادة → المحاضر والجودة والمشاركون المتأثرون (إلغاء الشهادة بسبب...).
